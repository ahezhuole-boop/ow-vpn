# 正式发布检查清单

## 品牌与官网
- [ ] 确定独有品牌名、商标使用权和域名归属，替换 `OwnNode` 这一临时名。
- [ ] 更新 Flutter `lib/brand.dart`、网站文字、SVG 图标与应用启动图标。
- [ ] 购买并配置域名、启用 HTTPS、配置联系邮箱、部署静态网站。
- [ ] 准备真实的应用介绍、测试范围、用户帮助与故障反馈。

## 应用工程
- [ ] 在支持的 Flutter/Dart 环境运行 `flutter create`、`flutter pub get`、`flutter analyze`、`flutter test`。
- [ ] 审核当前插件版本、底层 sing-box 版本及兼容范围，修复不兼容 API。
- [ ] Android 真机：导入配置、VPN 权限、持续前台服务、断线重连、待机恢复、IPv6/DNS 泄漏测试。
- [ ] Windows 真机：服务安装与卸载、提权、TUN/系统代理、兼容其他网络软件、注销与重启。
- [ ] 每种宣称支持的协议进行实际连接测试（尤其 WireGuard endpoint 的 JSON 配置）。
- [ ] 独立完成安全审查、日志与敏感凭据保护，避免在崩溃日志中泄漏订阅令牌。
- [ ] 发布包签名、包名、版本管理与自动更新策略；Windows 发布包包含运行需要的 DLL/组件。

## 运营与合规
- [ ] 确认部署地和用户所在地网络、个人数据、税务、支付相关要求。
- [ ] 公开准确的隐私政策（不能直接照搬 `website/privacy.html` 草案）、条款、联系与退款流程。
- [ ] 按 Google Play VPNService 政策完成声明、显著披露和必要的用户同意。
- [ ] 完成 GPL 许可证、著作权声明、源代码提供等义务。
- [ ] 上线后维护漏洞修复、节点权限吊销及应急响应流程。
